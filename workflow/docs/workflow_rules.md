# Workflow Rules v1

1. Follow the stage order unless a human explicitly asks to run a single stage.
2. Keep Stage 1 product-level only.
3. Keep Stage 2 implementation-free and verification-aware.
4. Stage 4 must inspect repository evidence before drawing conclusions.
5. Stage 5 must provide at least two solution options and one recommendation.
6. Stage 6 must produce atomic tasks and rollout gates.
7. Stage 7 must explicitly identify schema drift and improvement actions.
8. Prefer incremental integration over rewrite.
