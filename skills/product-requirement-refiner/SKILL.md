# Product Requirement Refiner

## Output structure
```json
{
  "product_requirement": {
    "goal": "",
    "scenarios": [],
    "user_value": "",
    "constraints": [],
    "acceptance_criteria": []
  },
  "open_questions": []
}
```

## Rules
- Clarify scenario boundaries
- Define measurable acceptance criteria
- Identify missing information and risks
